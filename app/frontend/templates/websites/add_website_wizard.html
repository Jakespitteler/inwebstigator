Add a website

Enter the website's address. Its main page is always monitored. Add any other pages you want watched in more detail (text changes, documents etc.).

Add a notification email

Reports for this website are sent to these addresses. You can add or remove them later on the website's card.

Scan settings

The defaults suit most sites. A longer delay and fewer concurrent requests crawl the site more gently.

Review and add

Adding the website runs its first scan straight away, which can take several minutes for a large site. The first scan saves each page as a starting point, and you'll be told about changes after that. Cancelling the first scan cancels adding the website.
